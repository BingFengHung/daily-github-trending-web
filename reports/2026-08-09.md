## 🌟 二、精選熱門項目深度剖析

### 1. [firecrawl/anydoc](https://github.com/firecrawl/anydoc)

- **⭐ Star 數**：12,154
- **主要語言**：Rust（提供 Node.js 與 Python 綁定）
- **核心功能亮點**：
  由知名爬蟲/資料擷取平台 Firecrawl 推出的核心模組，專為將各種常見文件格式（Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF）轉譯為極致乾淨的 Markdown 格式而設計。底層採用 Rust 撰寫，確保極高的解析速度與記憶體安全性，並透過 FFI 提供了 Node.js 和 Python 的 SDK 綁定。
- **解決的技術痛點**：
  在建構 RAG（檢索增強生成）系統或 LLM 資料管道時，異質文件（特別是舊版 Office 與複雜 PDF）的解析往往非常昂貴且容易混亂。[firecrawl/anydoc](https://github.com/firecrawl/anydoc) 解決了傳統解析器轉換品質差、包含大量贅餘標籤、且執行效率低下的問題。
- **適合的應用場景**：
  建構大型知識庫、RAG 向量資料庫預處理管道、AI Agent 文件閱讀模組、企業內部異質文檔自動化轉檔系統。

### 2. [0xwilliamortiz/claude-red](https://github.com/0xwilliamortiz/claude-red)

- **⭐ Star 數**：681
- **主要語言**：JavaScript / Markdown
- **核心功能亮點**：
  [0xwilliamortiz/claude-red](https://github.com/0xwilliamortiz/claude-red) 是一套專為 Claude Agent 設計的「進攻性資安（Offensive Security）」專家技能庫。專案採用結構化的 `SKILL.md` 格式，預先注入領域專家級的滲透測試與漏洞利用方法論。覆蓋範圍從 SQL 注入（SQLi）、Shellcode 撰寫、EDR（端點偵測與回應）避開，到 Exploit 開發等高階資安防護測試。
- **解決的技術痛點**：
  通用 AI 模型雖然具備資安知識，但缺乏系統性的資安測試思維框架與精準的步驟指引。[claude-red](https://github.com/0xwilliamortiz/claude-red) 將資安專家的經驗「程式碼化」，讓 Agent 能夠像資深紅隊演練員一樣，以高度結構化的思考鏈執行安全性檢測。
- **適合的應用場景**：
  紅隊滲透測試自動化、企業軟體資安弱點掃描輔助、安全研究員概念驗證（PoC）開發助手。

### 3. [KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing)

- **⭐ Star 數**：1,989
- **主要語言**：Python
- **核心功能亮點**：
  這是一套專門矯正 AI 寫作習慣的通用創作與改稿 Skill。[KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing) 透過精雕細琢的 Prompt 架構與邏輯規範，消解 AI 經常出現的「套話、空話、過度排比與僵硬轉折」，使生成出來的中文內容具有真人說話的口吻、情緒起伏與具體細節。
- **解決的技術痛點**：
  主流 LLM 在中文寫作上普遍存在「AI 味過重」（如：總結性套話、毫無感情的列舉、過度公文化用語）的問題，使得 AI 產出的行銷文案或文章極易被讀者識破並產生排斥感。
- **適合的應用場景**：
  自媒體文章創作、行銷文案撰寫、社群媒體貼文擬定、電子郵件潤飾與個人履歷改寫。

### 4. [Binaryify/open-kimi-ppt-skill](https://github.com/Binaryify/open-kimi-ppt-skill)

- **⭐ Star 數**：1,588
- **主要語言**：未標示（包含前編輯器套件）
- **核心功能亮點**：
  非官方的 Kimi Slides 技能擴充套件，專為 AI Agent 打造。它能讓 Agent 生成可編輯的簡報格式（PPTD 與 PPTX），同時附帶一個本地端的瀏覽器簡報編輯器。使用者既能讓 Agent 自動產出簡報架構與設計，又能透過本地介面進行即時微調。
- **解決的技術痛點**：
  過去 AI 生成簡報往往只能直接導出不可修改的圖片或格式僵硬的 PDF/PPT，導致使用者很難調整排版細節。[Binaryify/open-kimi-ppt-skill](https://github.com/Binaryify/open-kimi-ppt-skill) 結合了「Agent 自動生成」與「本地可互動編輯器」，完美閉環了 AI 簡報製作的最後一哩路。
- **適合的應用場景**：
  AI 驅動的工作彙報製作、演講簡報快速草稿生成、自動化簡報製作 Agent 開發。
