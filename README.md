# 🚀 GitHub Trending 每日 AI 報告儀表板

歡迎來到 **GitHub Trending 每日 AI 科技日報** 官方網站！

本站由 **Cloudflare Worker 雲端服務** 每日自動抓取 GitHub 當前最火爆的熱門開源專案，並透過 AI Agent 進行繁體中文深度解讀與結構化分析。

---

## 📌 網站功能與使用指引

* 📅 **每日熱門報告**：請點擊左側選單 **`📅 每日技術報告`** 閱讀每一天的最新熱門專案解讀。
 * 🔍 **全文搜尋功能**：使用頂部搜尋列（`🔍 搜尋技術關鍵字...`），可輸入程式語言（如 Python, Rust, Go）、關鍵字（如LLM, Agent, Web）進行跨日報告搜尋。
 * * 📱 **PWA 手機 App 支援**：本站支援 PWA 技術！點擊手機瀏覽器選單
**「新增至主畫面」**，即可將本站安裝為手機桌面專屬 App，並支援離線閱讀。

---

## 📊 報告架構特色

每一份每日報告皆包含：
1. **今日熱門技術趨勢總覽**（掌握最新技術風向標）
2. **精選項目深度剖析**（核心亮點、解決痛點、應用場景）
3. **熱門清單完整彙整表格**（附帶可點擊 GitHub 專案超連結）
